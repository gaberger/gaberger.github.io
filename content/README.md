# Content

The posts and pages of A Field CTO Perspective, served at
https://gaberger.github.io.

- `posts/<slug>/index.md`: one folder per post, with front matter (title, date,
  categories, tags) and its images alongside. Each post is published at
  `/<year>/<month>/<slug>/`.
- `about.md`: the About page.

The three 2017 posts were recovered from the original Hugo build, which never
had its source committed. The Facebook fabric post links one image from
Facebook's CDN that was never stored in the repo.

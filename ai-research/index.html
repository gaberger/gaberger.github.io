Local inference and edge serving

  • Tenstorrent stack Tenstorrent

    We own a QuietBox 2

    The open software stack for our Tenstorrent QuietBox 2. tt-metal (TT-NN ops + TT-Metalium kernels) is the core, tt-forge is the MLIR compiler for PyTorch/JAX, tt-inference-server serves models with vLLM, and tt-studio is a web GUI to deploy and chat with models. Latest tt-metal: v0.81.1 (Oct 23, 2026). Latest tt-inference-server: v0.26.0 (Oct 30, 2026) , adding QuietBox 2 support for K2-Horizon-7B, Muse-Glimmer-30B, Kolibri-1-BF16, gemma-4-26B-A4B-it and granite-4.2-30b.

    Apache-2.0 · ★ 1.7k tt-metal, Oct 31, 2026

Multi-agent orchestration

  • DeepSeek Super-agent dsh-superagent

    New Nov 1

    One always-on agent across chat, GitHub and email. A filter screens events, a small, fast Router talks to people and hands out tasks, and isolated Workers each own one task, with the strongest model on the hard ones. Long jobs run async; a Watchdog catches stuck workers. In DeepSeek's simulation, p95 tasks finished in 15.7 min vs about 29 min for one session, at 2 to 4x the tokens.

    MIT Research prototype for DeepSeek Harness, not a product · ★ 7.0k Nov 1, 2026

    GitHub ↗Article ↗Harness ↗

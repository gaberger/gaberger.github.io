Gooseaardappel (Wouter van Oortmerssen)New Nov 12, 2026LanguageA new memory-safe systems language from the creator of FlatBuffers and Lobster. It has no heap, no GC, no reference counting and no lifetime annotations: every value lives inline on compiler-managed data stacks, so freeing a million-element structure is a single store. Compiles a whole program to one C file and calls C directly; a bundled TinyCC backend runs programs in-process. Threads share no memory and pass flat values over typed queues. Claims 1.16x the speed of hand-optimized C++ and 1.12x safe Rust across 16 of its own benchmarks. Much of the code and docs are AI-written; 603 points on Hacker News (Nov 2026).Apache-2.03.5k, Nov 12, 2026GitHubSiteHN

Experiments

Smaller things I’ve tried in the open: prototypes, workshop repos and ideas that may or may not grow up. The finished work is on the Projects page.

Experiments

  • apidiff

    An API migration toolkit. Compares OpenAPI specs across versions, flags breaking changes, writes migration guides and emits a schema-valid changeset that humans and machines can both read.

    JavaScript · No license yet · Experiment

  • specdiff

    The first cut of apidiff, with a web UI. Compares OpenAPI specs and turns the differences into migration checklists with severity and timelines.

    JavaScript · No license yet · Prototype

  • rlm-mcp-server

    An MCP server for Recursive Language Model primitives: decompose an input too big for the context window, analyze each chunk, then aggregate the results.

    Node.js · No license yet · Experiment

  • tessl-carnival

    My copy of the AI DevCon NYC 2026 workshop repo: a browser carnival where labeling an issue sends an agent to ship a new game, built as a software factory one skill at a time.

    JavaScript · MIT · Workshop

  • fireworks-extension

    A browser extension for Firefox and Chrome that sets off particle fireworks on the pages and elements you choose.

    JavaScript · MIT · Experiment

Deprecated

  • hex

    The original operating system for AI agents: process management, architecture enforcement, swarm coordination and inference routing. No longer maintained; its ideas live on in hexa.

    Rust · MIT · Deprecated: superseded by hexa
